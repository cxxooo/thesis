# Thesis — desktop companions

Small desktop apps made for my thesis at ArtCenter College of Design.
Each one sits on the desktop and turns an everyday computer habit into something you can see.

| Project | What it is |
|---|---|
| [Keystroke Loom](loom) | A loom that weaves whatever you type, in any app. Colour comes from the key's column, shape from its row. |
| [Palm Tree Pet](palm-tree) | A palm tree that grows old leaves over time. Click them to trim it. |

Both are Electron apps for macOS. See each project's README to run it.
